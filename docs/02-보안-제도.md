# 2. 보안·제도 검토

## 2.1 핵심 질문

> 학사·행정 시스템의 **소스 코드와 DB 스키마**를 외부 LLM API로 보내도 되는가?

에이전트는 좋은 코드를 만들려고 기존 화면 소스, 테이블·컬럼 정의, 공통코드, 기존 SP를 컨텍스트로 보낸다. 무엇이 밖으로 나가는지부터 정리해야 한다.

## 2.2 외부로 나가는 정보 분류

| 정보 | 예 | 민감도 | 외부 전송 판단 (안) |
|------|----|--------|-------------------|
| 화면 명세 (자연어) | "학적 변동 이력 조회 화면" | 낮음 | 허용 |
| WebSquare 공통 템플릿·컴포넌트 사용법 | 그리드 설정, 공통 함수 호출 | 낮음 | 허용 |
| 테이블·컬럼 이름과 설명 | `TB_STD_CHG.CHG_DIV_CD` | 중간 | 조건부 (시스템 구조 노출) |
| 기존 SP 본문 | 업무 규칙, 권한 처리 로직 | 중간~높음 | 조건부 또는 금지 |
| 접속 정보·계정 | DB 접속 문자열, 비밀번호 | 매우 높음 | **금지** |
| 실데이터 | 학번, 성명, 주민번호, 성적 | 매우 높음 | **금지** |

**원칙: 실데이터와 자격증명은 어떤 경우에도 보내지 않는다.** 이를 사람의 주의에 맡기지 않고, 에이전트의 컨텍스트 수집 단계에서 기술적으로 막는다 (예: 스키마는 DDL만 읽고 `SELECT` 결과는 수집하지 않음, 설정 파일 경로는 수집 대상에서 제외).

## 2.3 확인할 규정과 담당

| 항목 | 확인할 내용 | 담당 (확인 필요) |
|------|-----------|----------------|
| 망분리 | 개발 PC가 업무망인지 인터넷망인지, 외부 API 호출이 가능한지 | 정보보호 담당 |
| 국가·공공기관 클라우드·AI 이용 지침 | 대학이 적용 대상인지, 외부 생성형 AI 사용 시 승인 절차 | 정보보호 담당, 기획 |
| 개인정보보호법 | 개인정보 처리 위탁에 해당하는지 (실데이터를 안 보내면 해당 없음을 문서로 남김) | 개인정보보호 담당 |
| 학교 자체 보안 규정 | 소스 코드 외부 반출 규정 | 정보보호 담당 |
| 계약 조건 | LLM 제공사의 데이터 보존·학습 이용 정책 (API 이용 약관, 데이터 보존 기간, 학습 미사용 조건) | 구매, 정보보호 |

정확한 지침명과 조항은 담당 부서 확인을 거쳐 이 표에 채운다. 이 문서는 무엇을 물어야 하는지 정리한 것이지 법률 판단이 아니다.

## 2.4 배치 대안 비교

| 대안 | 설명 | 장점 | 단점 | 망분리 환경 |
|------|------|------|------|------------|
| A. 외부 상용 API 직접 호출 | 개발 PC에서 LLM API 호출 | 성능 최고, 바로 시작 | 소스·스키마 외부 전송, 승인 필요 | 인터넷망 PC에서만 가능 |
| B. 전용 계약 클라우드 | 기업용 계약 (데이터 미학습·보존 기간 제한, 국내 리전 등) | 성능 유지, 계약으로 통제 | 비용, 계약 절차 | 중계 서버 필요 |
| C. 사내 LLM 게이트웨이 | 학교 서버가 중계하며 마스킹·로깅·차단 적용 후 외부 호출 | 감사 로그, 정책을 한 곳에서 적용 | 구축·운영 부담 | 게이트웨이만 외부 연결 |
| D. 온프레미스 오픈 모델 | 학교 GPU 서버에서 공개 가중치 모델 운영 | 데이터가 밖으로 안 나감 | GPU 비용, 코드 생성 품질이 상용보다 낮을 수 있음, 운영 인력 | 완전 내부 가능 |

**검토 의견 (안)**

- **1단계(개인 검증)**: A를 쓰되 실데이터·자격증명을 차단하고, 스키마는 실험용 과제에 필요한 테이블만 넣는다.
- **2단계 이후**: C(게이트웨이)를 기본으로 둔다. 모델을 B나 D로 바꿔도 개발자 쪽 설정은 그대로 두려는 것이다.
- **D는 별도 PoC**로 같은 효과 검증 과제를 돌려서 품질 차이를 숫자로 확인한 뒤 결정한다. 과제가 같으므로 01 문서의 실험 틀을 그대로 쓸 수 있다.

## 2.5 게이트웨이에 넣을 통제 (C안 기준)

- 요청 본문에서 주민번호·휴대전화·이메일 패턴을 탐지하면 차단하고 기록
- 설정 파일, `.env`, 접속 정보 패턴 차단
- 사용자별 요청·응답 로그 보관 (감사용, 보관 기간은 규정에 따름)
- 허용 모델·허용 사용자 목록 관리
- 사용량·비용 집계
