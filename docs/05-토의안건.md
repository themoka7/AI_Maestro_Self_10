# 5. 토의 안건

| 순서 | 내용 | 시간 |
|------|------|------|

## 안건

### 안건 1. 효과 검증 과제와 판단 기준

- 실험 과제로 어떤 실제 화면을 쓸 것인가?
- 교차 실험이 가능하도록 참여자 2명과 과제 2개를 확보할 수 있는가?
- "소요 시간 30% 이상 단축, 상·중 결함 비증가"라는 기준은 적절한가?
- AI 교과목 이수율 조회 화면(공문 요청)은 예상 1주 → 실제 반나절이었다. 스킬을 만든 본인이 아닌 개발자에게도 같은 효과가 날까?

### 안건 2. 외부 LLM 사용 범위

- 테이블·컬럼 이름은 외부로 보내도 되는가? 기존 SP 본문은?
- 1단계를 외부 API로 시작해도 되는가, 아니면 승인부터 받아야 하는가?
- 온프레미스 모델 PoC를 지금 병행할 가치가 있는가? (GPU 자원 확보 가능 여부)

### 안건 3. 품질 게이트

- ES5 검사와 개인정보 검사를 **에이전트를 쓰지 않은 코드에도** 적용할 것인가?
- 개인정보 컬럼 목록은 누가 관리하는가? (메타 시스템 연계 가능 여부)
- 게이트 실패 시 예외 승인 절차는 어떻게 할 것인가?

### 안건 4. 확장

- 2단계 시범 팀은 어디로 할 것인가?
- 개인 코딩 베이스 스킬을 팀 공용으로 옮길 때 무엇을 표준화하고 무엇을 개인 몫으로 남길 것인가?
- 팀 공용 설정 저장소 관리자는 누구로 할 것인가?
- 외주 개발사에도 적용할 것인가?
